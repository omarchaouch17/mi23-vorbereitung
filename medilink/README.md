# MediLink

## Live-Demo

https://medilink-trbk.onrender.com

Hinweise:
- Es werden nur erfundene Demo-Daten verwendet, bitte keine echten Gesundheitsdaten eingeben.
- Die Datenbank wird bei jedem Neustart oder Deploy zurückgesetzt (SQLite auf der kostenlosen Render-Stufe).
- Beim ersten Aufruf kann das Laden bis zu einer Minute dauern, weil die kostenlose Instanz im Leerlauf schläft.
- Der Framingham-Score dient nur der Veranschaulichung und ist kein Diagnoseinstrument.
